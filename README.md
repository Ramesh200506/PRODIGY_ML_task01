# PRODIGY_ML_task01

## 🏠 House Price Prediction Using Linear Regression

This project was completed as part of my **Machine Learning Internship at Prodigy Infotech**.

The objective of this project is to build a **Linear Regression model** that predicts house prices based on important features such as **square footage, number of bedrooms, and number of bathrooms**.

## 📌 Project Objective

The main objective is to understand and implement a supervised machine learning regression model for predicting house prices.

The project includes:

- Loading and understanding the dataset
- Data preprocessing
- Selecting relevant features
- Splitting the dataset into training and testing sets
- Training a Linear Regression model
- Predicting house prices
- Evaluating model performance
- Visualizing the results

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 📊 Features Used

The model uses the following features:

- Square Footage
- Number of Bedrooms
- Number of Bathrooms

### Target Variable

- House Price

## 🤖 Machine Learning Algorithm

### Linear Regression

Linear Regression is a supervised machine learning algorithm used to predict a continuous numerical value based on one or more input features.

In this project, the model learns the relationship between house characteristics and their corresponding prices.
